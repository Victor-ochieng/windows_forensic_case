
A batch script named "notepab.bat" was created and designed to mimic a legitimate application.

The script launches Notepad to appear harmless while executing hidden commands in the background.

Execution of the script was confirmed through system artifacts indicating program launch activity.

Analysis of the script shows it collects system network configuration and stores it in "capture.txt".

The script runs a traceroute command and logs the results into "log.txt".

The script enumerates running processes using tasklist and writes the output to "user.txt".

The behavior of the script indicates it was used to collect system and network information without user awareness.
